Content Ops Playbook — Ekspedisi Container
  1. Template. Buat template SEO dengan AI, sesuai kebutuhan perusahaan logistik.
  2. Data real. Inject rute Origin–Destinasi + harga update tgl 1–6 tiap bulan.
  3. Publish massal. 20 halaman/hari. Origin: Surabaya / Jakarta / Sidoarjo. ±36–40 kota / origin.
  4. Ranking check. Keyword “ekspedisi container [origin] [destinasi]”, pantau Page 1–2.
  5. Iterasi. Bandingkan SERP kompetitor. Posisi 4+ saya benahi template-nya.
  6. Ads hygiene. Negative keyword Google Ads tiap pagi sebelum jam 08.00.
